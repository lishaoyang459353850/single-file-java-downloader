单文件 Java 多线程下载器

一个仅含单个 .java 文件的轻量级 HTTP 下载工具，支持 8 线程并发、断点续传、进度可视化、DNS 缓存与代理配置。

查看仓库 快速上手
Java 100% ⭐ 1 MIT JDK 8+

✨ 核心特性

⚡
8 线程并发
分块下载，充分利用带宽，大幅提升大文件下载速度。
 ⏯️
断点续传
支持暂停/恢复，意外中断后自动从上次断点继续。
 📊
进度可视化
实时显示下载百分比、速度、已用时间与预估剩余时间。
 🌐
DNS 缓存
内置 DNS 解析缓存，减少重复查询延迟。
 🔌
代理支持
支持 HTTP/HTTPS/SOCKS 代理配置。
 🔄
自动重试
连接失败自动重试，可配置最大重试次数。
 🧩
单文件零依赖
仅一个 Java 源文件，无需第三方库，JDK 8+ 即可编译运行。
 📝
详细日志
分级日志输出，方便调试与监控下载状态。

🚀 快速开始

方式一：使用 PowerShell 脚本（推荐 Windows）

powershell -ExecutionPolicy Bypass -File build.ps1

方式二：手动编译与运行

javac PyDownload.java
java PyDownload [URL] [选项...]

打包为 JAR

jar cfe downloader.jar PyDownload *.class

功能说明
多线程下载8 线程并行分块下载

⚙️ 首次运行说明

请确保已安装 JDK 8 或更高版本，并将 java 加入环境变量。首次运行时会自动创建配置文件 config.properties，可根据需要调整线程数、重试策略等参数。
